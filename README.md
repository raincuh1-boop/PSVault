PSVault

A native PlayStation 4 homebrew storefront.

PSVault aims to provide a unified interface for browsing and managing authorized homebrew packages.

Planned Features

- Native PS4 interface
- Controller-friendly navigation
- Online game catalogue
- Offline catalogue cache
- Search and categories
- Download manager
- Retry and resumable downloads
- Package management integration

Architecture

- Native application: C
- Target: PlayStation 4
- Development toolchain: OpenOrbis
- Build system: GitHub Actions
- Catalogue: JSON-based online database

Development Status

🚧 Early development
